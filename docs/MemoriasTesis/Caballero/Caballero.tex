\newcommand{\resumen}{
Este trabajo evalúa si el modelo de redes financieras duales de Venegas, que extiende el marco de negociación bilateral de Jalan y Chakrabarti, puede calibrarse con datos reales. El modelo predice que una infraestructura alternativa, donde el contrato prohibido en la red tradicional sí puede ejecutarse, recupera por completo el bienestar perdido por una restricción regulatoria, pero ese resultado se obtiene con parámetros ilustrativos. Como caso de aplicación se estudia el programa Crédito Corfo Mipyme, en que CORFO financia a las MiPyMEs a través de intermediarios financieros no bancarios y no de forma directa. Se levantaron las fuentes públicas disponibles, se declararon los supuestos para las variables que ninguna fuente observa y se contrastaron los datos con los requisitos de identificación del marco teórico. El diagnóstico muestra que el panel disponible queda por debajo del tamaño mínimo que exige el Teorema 5 y que, por la estructura bipartita de la red del programa, la matriz de covarianzas no puede recuperarse por completo, ni siquiera agregando intermediarios o periodos. Se identifican además las aristas de fondeo bancario que sí permitirían completar la identificación.
}
